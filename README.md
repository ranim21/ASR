# ASR
ASR Project include this features:
* OCR & extraction : Conversion automatique d'images et PDFs en
texte et extraction d'entités structurées 
Summarisation : Pré-entraînement et intégration d'un modèle de
résumé de documents non structurés
Stockage : Export des résultats en JSON vers Firebase via une
architecture de classification documentaire en amon
